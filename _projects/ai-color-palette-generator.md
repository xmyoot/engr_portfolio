A small web app that uses AI to propose visually pleasing color palettes based on prompts, moods, or reference images. Designed for designers and developers who want quick theme ideas.

# Key features
- Prompt-driven palette generation (e.g., "warm autumn", "neon cyberpunk").
- Exportable palettes (HEX values) and simple previews for UI components.
- Optionally uses OpenAI to refine palettes and provide usage notes.

# Tech stack
- Front end: React
- AI: OpenAI API

# Usage
- Repository and setup: https://www.github.com/xmyoot/style-pallete
- Provide prompts or upload a reference to receive suggested palettes and color swatches.
